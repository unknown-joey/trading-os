# 03. 仓位管理规则结构

这份文档只整理仓位管理规则。

暂时不实现市场状态识别，不判断牛熊、趋势、低位或高位。

仓位管理先拆成两个市场、三个仓位类型：

```text
市场：股票、期货
仓位类型：老仓、新仓、网格仓
```

每个市场下，每个仓位类型都按同一结构整理：

```text
入场/建仓逻辑
最大资金占比/仓位限制
风险控制方式
止盈/退出规则
```

## 股票

### 老仓

入场/建仓逻辑：

```text
按股票市值规模控制仓位。
仓位买够后不频繁操作，用时间对冲风险。
```

最大资金占比/仓位限制：

```text
大盘股：总市值 500 亿元以上，可用约 40% 仓位。
中盘股：100 亿到 500 亿，可用约 30% 仓位。
小盘股：40 亿到 100 亿，可用约 25% 仓位。
微盘股：40 亿以下，仓位更低，可设为 10% 左右。
```

风险控制方式：

```text
老仓风控价格一般不移动，不以主动止损为主。
```

止盈/退出规则：

```text
仓位买够后不频繁操作，用时间对冲风险。
```

### 新仓

入场/建仓逻辑：

```text
新仓必须以止损位反推买入量。
止损位要尽量远离市场共识止损位。
```

最大资金占比/仓位限制：

```text
单笔止损不能超过总资金 1%。
```

风险控制方式：

```text
所有新增风险仓都必须有止损。
单笔新增风险不超过总资金 1%。
```

止盈/退出规则：

```text
盈利达到 2R 后，将止损推到开仓价，进入保本状态。
```

### 网格仓

入场/建仓逻辑：

```text
适合 ETF、大盘股、长期不容易退市的标的。
底部区间只买入，中间区间买入加卖出，上方区间逐步卖出或停止加仓。
```

最大资金占比/仓位限制：

```text
网格资金按压力测试计算，已经分配给网格的资金不能随意抽出。
```

风险控制方式：

```text
跌到风险价格以下不强制卖出，但不能继续无计划加仓。
```

止盈/退出规则：

```text
底部区间只买入，中间区间买入加卖出，上方区间逐步卖出或停止加仓。
```

## 期货

### 老仓

入场/建仓逻辑：

```text
采用“现货做期货”的思路。
可以把总资金约 30% 放在期货账户，剩余 70% 做灵活理财或备用资金。
单品种首次开仓只开“去杠杆满仓”的 50% 以内，必须至少保留一次加仓机会。
```

最大资金占比/仓位限制：

```text
期货总仓位平时不得超过 50%。
重大节假日、休市前，总仓位不超过 25%。
8 天以上长假最好不留仓。
单一品种最高 3 倍杠杆。
节假日前单品种杠杆降到 2 倍以内。
铜、橡胶等波动大的品种仓位应更轻。
```

风险控制方式：

```text
老仓风控价格一般不移动，不以主动止损为主，用时间和低杠杆对冲风险。
```

止盈/退出规则：

```text
8 天以上长假最好不留仓。
重大节假日、休市前，总仓位不超过 25%。
```

### 新仓

入场/建仓逻辑：

```text
每一次加仓都视为独立新仓。
使用“以损定量”：根据止损位距离反推开仓手数。
止损位要放在共识止损位之外，必要时缩小仓位。
```

最大资金占比/仓位限制：

```text
单笔止损不能超过总资金 1%。
```

风险控制方式：

```text
所有新仓必须带止损。
单笔止损不能超过总资金 1%。
```

止盈/退出规则：

```text
盈利达到 2R 后，将止损推到开仓价，进入保本状态。
如果后续新仓连续 2 个被打掉，应停止继续加仓或考虑退出。
```

### 网格仓

入场/建仓逻辑：

```text
选择短期波动大的品种。
最好和长期持有品种相关性低。
适合不会轻易归零、长期有均值回归逻辑的品种。
底部区间只买入，中间区间买入加卖出，上方区间逐步卖出或停止加仓。
```

最大资金占比/仓位限制：

```text
期货网格必须先做压力测试。
每手资金占用 = 从入场价跌到极端压力价格时的浮亏 + 保证金。
压力价格可以取历史低点的一半，或根据品种特性手动设置。
根据可分配资金计算最多能做几手。
网格占用资金不能随意挪用，因为它是用来承受极端下跌的。
```

风险控制方式：

```text
期货网格必须先做压力测试。
网格占用资金不能随意挪用，因为它是用来承受极端下跌的。
```

止盈/退出规则：

```text
底部区间只买入，中间区间买入加卖出，上方区间逐步卖出或停止加仓。
```

## 全局规则

```text
强相关品种只选择一个，避免表面多品种、实际同方向暴露。
所有新增风险仓都必须有止损。
单笔新增风险不超过总资金 1%。
盈利达到 2R 后保本推进。
不允许首次开仓就打满。
生存优先于收益率。
先不实现市场状态识别，只整理仓位管理规则结构。
```
