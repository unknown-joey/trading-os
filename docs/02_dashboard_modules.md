# 02. 每个交易问题启动哪些量化检查

## 0. 总图

```text
交易问题        量化角色              解决的问题
------------------------------------------------------------
入场前          生存检查              这个品种和账户能不能碰
入场            仓位计算/压力测试      第一笔最多开多少
加仓            新仓风险计算          新增仓位错了亏多少
止损            触发检查              是否退出或停止补仓
止盈            R 倍数检查            是否推保本或释放风险
总风控          组合暴露检查          账户整体有没有失控
复盘            规则执行检查          哪些地方破坏了规则
```

仓位管理规则本身按两个市场、三个仓位类型组织：

```text
市场：股票、期货
仓位类型：老仓、新仓、网格仓
规则结构：入场/建仓逻辑、最大资金占比/仓位限制、风险控制方式、止盈/退出规则
```

当前暂不启动市场状态识别。

## 1. 入场前：能不能碰

你面对的问题：

```text
这个品种能不能做？
账户现在还能不能开新仓？
这个品种是不是和已有持仓重复？
```

启动的量化检查：

```text
品种生存检查。
账户总仓位检查。
相关性检查。
节假日模式检查。
```

需要的数据：

```text
账户资金。
当前持仓。
当前价格。
极端价格。
合约乘数。
风险组。
```

输出结果：

```text
允许观察。
允许入场。
禁止入场。
需要先降仓。
需要换品种。
```

它不回答：

```text
明天会不会涨。
这个品种是不是一定有机会。
```

## 2. 入场：第一笔怎么开

你面对的问题：

```text
如果现在开第一笔，开多少？
如果错了，亏多少？
如果继续下跌，账户会怎样？
```

低位网格启动：

```text
网格压力测试。
极端下跌模拟。
最大补仓层数检查。
最大资金占用检查。
```

趋势试错启动：

```text
止损距离计算。
单笔风险计算。
可开手数计算。
总仓位占用检查。
```

输出结果：

```text
网格：允许轻仓网格 / 缩小网格 / 放弃。
趋势：允许开 N 手 / 减少手数 / 放弃。
```

入场规则：

```text
低位网格必须先证明继续跌也不会死。
趋势入场必须先证明止损亏损不超过 1%。
```

## 3. 加仓：什么时候能加

你面对的问题：

```text
前一笔赚钱了，要不要加？
加多少不会让风险失控？
加完以后账户是不是太重？
```

启动的量化检查：

```text
新增仓位风险计算。
已有未保本风险统计。
总名义仓位检查。
同风险组暴露检查。
```

需要的数据：

```text
新增开仓价。
新增止损价。
已有持仓状态。
账户剩余风险额度。
当前总仓位。
```

输出结果：

```text
允许加 N 手。
需要等老仓推保本后再加。
需要减少加仓手数。
禁止加仓。
```

加仓规则：

```text
每次加仓都是一笔新交易。
每笔新交易都必须有止损。
每笔新交易最大亏损仍然按 1% 算。
```

## 4. 止损：错了怎么办

你面对的问题：

```text
这笔仓是不是已经错了？
是不是应该退出？
网格是不是不能继续补了？
账户整体是不是已经超出承受能力？
```

趋势仓启动：

```text
止损触发检查。
实际亏损检查。
计划亏损对比。
```

网格仓启动：

```text
最大层数检查。
最大浮亏检查。
剩余资金检查。
继续下跌压力测试。
```

组合层面启动：

```text
总仓位检查。
同风险组共振检查。
节假日风险检查。
```

输出结果：

```text
趋势仓触发止损。
网格停止补仓。
账户先降风险。
继续持有但不加仓。
```

止损规则：

```text
趋势仓按止损走。
网格仓按压力边界走。
组合风险优先级高于单个品种判断。
```

## 5. 止盈：对了以后怎么办

你面对的问题：

```text
赚了以后是卖掉，还是继续拿？
什么时候把风险锁住？
什么时候允许下一笔加仓？
```

启动的量化检查：

```text
R 倍数计算。
2R 触发检查。
保本状态检查。
风险额度释放计算。
```

需要的数据：

```text
开仓价。
原始止损价。
当前价。
合约乘数。
持仓手数。
当前仓位状态。
```

输出结果：

```text
未到 2R，继续按原止损管理。
达到 2R，止损抬到开仓价。
已经保本，继续持有。
释放风险额度，允许寻找下一笔。
```

止盈规则：

```text
第一步不是卖出，而是推保本。
推保本以后，这笔仓不再占用计划风险额度。
后续是否卖出，可以再单独设计趋势退出规则。
```

## 6. 总风控：账户整体有没有危险

你面对的问题：

```text
单笔都没错，但账户会不会整体出事？
品种是不是太相关？
节假日前是不是太重？
网格会不会一起补仓？
```

启动的量化检查：

```text
总名义仓位检查。
未保本风险合计。
风险组暴露统计。
节假日仓位上限检查。
极端情景压力测试。
```

输出结果：

```text
可交易。
谨慎，只能管理旧仓。
禁止新仓。
必须降仓。
```

总风控规则：

```text
平时总仓位不超过 50%。
节假日前总仓位不超过 25%。
同一风险组只保留一个主品种。
风险事件模式下暂停主动加仓。
```

## 7. 复盘：规则有没有被破坏

你面对的问题：

```text
这次亏损是规则内亏损，还是执行错误？
这次盈利有没有按规则推保本？
哪类错误反复出现？
```

启动的量化检查：

```text
交易计划记录。
实际盈亏记录。
R 倍数统计。
规则违规标记。
```

输出结果：

```text
规则内亏损。
超计划亏损。
未按规则推保本。
风险超限时仍开仓。
强相关重复下注。
```

复盘规则：

```text
先分清是系统问题还是执行问题。
如果是执行问题，优化流程。
如果是系统问题，修改规则。
如果无法量化检查，先保留人工确认。
```
